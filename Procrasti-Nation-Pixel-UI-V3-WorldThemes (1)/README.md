# Procrasti-Nation 🐌

A humorous procrastination tracker built as a zero-backend hackathon MVP.

## Features
- Task management
- Procrastination session timer
- Reason + task being avoided
- Reverse-reaction messages
- Achievements
- Dashboard statistics
- History
- Rule-based "AI" procrastination insights
- LocalStorage persistence
- Responsive UI

## Run
Just open `index.html` in a browser.

No installation or backend is required.

## Suggested hackathon extensions
1. Add Firebase/Supabase authentication and cloud sync.
2. Add real AI analysis through an API endpoint.
3. Add push notifications.
4. Add friend leaderboard.
5. Add weekly reports and charts.
